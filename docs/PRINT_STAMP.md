# 打印模板盖章

入口：系统管理 → 打印模板 → 设计 → 盖章区域。

1. 启用盖章区域，选择透明背景 PNG（不超过 256 KB，宽高不超过 2048 px）。
2. 拖动右侧预览中的虚线框，或输入距离、区域宽高，单位为毫米。图片等比显示，透明部分保留文字。
3. 保存版式。采购单、销售单、出入库单打印预览会使用此配置，可临时取消“显示印章”。

位置跟随明细下方的落款区，长明细分页后只在末页落款盖章；本版尚未提供固定纸张坐标、每页重复或骑缝章。印章图片按模板保存，与现有公司名称/Logo 的配置方式一致，尚未增加独立公司档案。历史模板默认不盖章。

图片在模板现有权限内持久化。Go / Java 均独立验证 PNG、尺寸、透明度及内容大小。普通编辑模板会保留版式；坏图、更换失败和保存失败保留原有效内容。未保存关闭遵循系统原有保护。
